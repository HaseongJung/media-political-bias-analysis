# 언론사별 정치 편향성 분석 (Media Political Bias Analysis)
![언론사별 정치 편향성](https://github.com/user-attachments/assets/85031f75-f910-41aa-917d-361bf7c09d0a)

## 📌 프로젝트 개요
본 프로젝트는 국내 주요 언론사의 기사 데이터를 수집하여, 자연어 처리(NLP) 기반 기법을 활용해 언론사별 정치적 편향성을 분석하고 시각화한 것입니다.  
편향성 점수, 토픽 분포, 감성 분석 등을 종합적으로 활용하여 각 언론사의 보도 성향을 계량적으로 측정하였습니다.

## 🎯 분석 목표
- 언론사의 기사 내용을 기반으로 정치적 성향(보수/진보) 및 편향도 측정
- 시각화를 통해 정치적 스펙트럼 상의 상대적 위치 추정
- 언론사별 정치 편향성 제공을 통해 보다 객관적인 정보 소비 기반 마련

## 📊 사용 데이터
- 수집 대상: 더불어민주당 / 국민의힘 관련 정치 기사 (제목 + 본문)
- 대상 언론사: 네이버 뉴스 구독 TOP 13 (MBC, YTN, SBS, JTBC 등)
- 수집 기간: 2020.09.02 ~ 2023.12.31
- 수집 방법: 웹 크롤링 (BeautifulSoup + requests)
- 데이터 수: 약 260,000건 (언론사별 약 2~3만 건)

## 🔍 분석 방법
1. **데이터 수집 및 전처리**
- 크롤링, 결측치 처리, 토큰화 및 불용어 제거
- 형태소 분석 및 품사 태깅 (KoNLPy 기반)
2. **토픽 모델링**
  - 해당 기사가 어느 정당에 대해 쓰여진 글인지 판별
  - TextRank, KeyBART, facebook/bart-large-mnli 기반 모델 비교
  - 가장 정확도가 높은 모델을 채택해 기사에 라벨링
3. **감성 분석**
  - 기사 제목 및 본문을 기반으로 긍정/부정/중립 감성 분류
  - KNU 한국어 감성 사전 활용
4. **언론사별 편향성 분석**
- 기사 감성값과 정당 토픽 라벨 기반 편향성 계산
- **편향성 지표 정의**:  
  `Bias Score = Avg(Sentiment for 국민의힘) - Avg(Sentiment for 더불어민주당)`
- 점수가 클수록 보수 성향, 작을수록 진보 성향
5. **결과 및 시각화**
- 언론사별 정당 토픽 분포 시각화
- 감성 비율 시각화 (긍/부정/중립)
- 정치 편향성 바 차트 시각화

## 📌 분석 인사이트 요약

### 🧠 정치 성향 분석
- 언론사들은 -2(진보) ~ +2(보수) 범위의 편향성 점수를 기준으로 분류됨
- **MBC, YTN, SBS**는 진보 성향, **매일경제, 아시아경제, 국민일보**는 보수 성향
- **JTBC, KBS, 한국경제**는 중립에 가까움

### 🗳️ 정당별 토픽 분포 분석
- 대부분 언론사는 **양당을 유사한 비율로 다룸**
- *아시아경제*, *국민일보*는 **국민의힘 관련 기사 비율**이 더 높음
- *MBC*, *한국경제*는 **더불어민주당 관련 기사 비율**이 높음

### 💬 감성 분석 결과
- 대다수 언론사의 정치 기사에서 **긍정보다 중립 또는 부정 감성이 우세**
- *한국경제*, *국민일보*, *경향신문*은 **부정 비율 50% 초과**
- *KBS*, *YTN*, *매일경제*는 **긍/중립/부정 간 균형** 유지

### 🔁 정치 성향과 감성의 관계
- 보수 성향 언론은 **더불어민주당 기사에 부정 감성**이 많을 가능성
- 진보 성향 언론은 **국민의힘 기사에 비판적 감성**이 더 많음
- *JTBC*, *KBS*는 모든 측면에서 **중립적 보도 성향**
