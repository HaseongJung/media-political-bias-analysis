# 언론사별 정치 편향성 분석 (Media Political Bias Analysis)

## 📌 프로젝트 개요
본 프로젝트는 국내 주요 언론사의 기사 내용을 텍스트 기반으로 분석하여, 정치적 편향성을 계량적으로 측정하는 것을 목표로 합니다. 뉴스 데이터 수집부터 텍스트 전처리, 토픽 모델링, 감성분석, 시각화까지 전 과정을 다루며, NLP 기반 데이터 분석 기법을 실제 사회 문제에 적용한 사례입니다.

## 🎯 분석 목표
- 언론사의 기사 내용을 기반으로 정치적 성향(보수/진보) 및 편향도 측정
- 시각화를 통해 정치적 스펙트럼 상의 상대적 위치 추정
- 언론사별 정치 편향성 제공을 통해 보다 객관적인 정보 소비 기반 마련
